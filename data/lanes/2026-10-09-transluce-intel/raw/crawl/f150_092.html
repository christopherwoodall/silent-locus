Murmuration

A one-person project that reads public internet records to find AI agents talking to each other or working toward a shared goal.

Status on 5 October 2026: two confirmed cases (ntfy, DSEWiki), one known agent forum read (1f916.ai; not a new swarm), one closed false alarm and a handful of weak leads.

1f916.ai report (5 October 2026): /observatory/1f916, 16 sections on the 7442 chain, other adoption chains, rhythm, community statistics and open questions. Dataset: github.com/maramasaeva/1f916-archive.

1f916.ai content analysis (6 October 2026): /observatory/1f916-content, 18 topic clusters, 20 message types and 12 themes of the 102,147 messages, with read precision per type and theme, examples with links and 32 figures.

1f916.ai economy analysis (6 October 2026): /observatory/1f916-economy, how agents on the forum are paid, how much, who pays and what the data shows about the money. 29 recorded payments total 69.35 USDC to 25 recipient handles; the page also holds treasury figures by source, 40 example messages with links and 18 figures.

Behavior (6 October 2026): /observatory/behavior, a separate reading of the same records against recent work on scheming, hidden channels, and model idiolects. Six directions, two rereadings of chains already on this site. Notes: github.com/maramasaeva/observatory-behavior.

Why the method changed on 5 October

Until 5 October the project counted new accounts, packages and pages per day. Counting finds busy days. The 29 September result passed a statistical test and failed when the pages were read.

A finding now needs content: a message an agent wrote, and either another agent acting on it or a shared goal across several runs. Two agents passing one note count. A thousand identical publishes may not.

How a result is graded

GradeMeaning
E0The item exists in a public record.
E1The item is itself a message, handoff, instruction or result left for others.
E2A second run or agent used it.
E3Several runs share one goal: the same target, the same task, the same place for results.

A finding needs E1 plus E2 or E3. Ordinary explanations are tried first: one person, a normal tool, a test script, one agent working alone. Each reading rule is written down and hashed before the real data is read.

What this cannot tell you

  • Who is behind anything. The project names no people, labs or companies as actors.
  • Whether a person steered the agents.
  • Anything that is not public.
  • Many earlier tests were limited by access (rate limits, missing keys, pages that did not load). An empty result there is incomplete.

AI tools help run the project. A person checks what is published. Mistakes are possible.

Words used

Agent
A program driven by an AI model that takes actions, such as fetching pages or editing a wiki.
Swarm
Several agents working at the same time with signs that they affect each other.
Mailbox
A public place that one agent writes to and another reads from: a wiki talk page, a paste, a notification channel.
Control
An ordinary comparison case used to check that a method can tell a real signal from background.
