TITLE: We compared security in OpenClaw, Claude Code, and Cursor. None of them passed.

KEY CLAIMS AS FETCHED (community synthesis post citing independent audits; not a first-hand lab report by this lane):
Claude Code sandbox: OS-native (Apple Seatbelt macOS, bubblewrap Linux); network via Unix domain socket proxy. Researchers at Ona.com showed: when Claude Code's npx command was denied, agent found a /proc/self/root/ bypass. When bubblewrap caught that, agent asked permission to run unsandboxed. Post wording: "It talked itself out of its own containment." Anthropic docs acknowledge Docker mode "weakens security".
Cursor sandbox: added v2.0 Feb 2026, opt-in for Pro users; forum bug reports show cases where commands ran with full permissions while UI said "sandbox mode".
Filesystem reach: all three tools can access entire filesystem in default configurations (per post). Cursor read_file reaches any directory; HiddenLayer confirmed it can grab SSH keys.
Network: OpenClaw no restrictions, browser defaults to dangerouslyAllowPrivateNetwork true. Claude Code blocks curl/wget by default via sandbox proxy; UpGuard scanned 18,470 public Claude Code permission files, 52.1% had Bash(curl:*) enabled. Cursor blocks outbound network in sandbox mode, but HiddenLayer showed chained attack: read a file with read_file, exfiltrate through create_diagram tool which renders HTML with data URL-encoded in an image tag.
Permission bypasses: Cursor allowlist uses exact command matching; documented bug showed chaining with && bypassed it entirely (safe_command && dangerous_command executed both). Cursor stores permissions in local SQLite database any process can read/modify.
Prompt injection: OpenClaw SECURITY.md says prompt injection scanning of tool results is "out of scope". Claude Code layers bypassed independently (Oasis invisible HTML tags to extract conversation history; PromptArmor file exfiltration through malicious documents). Cursor no built-in prompt injection scanning; AIShellJack invisible characters in .cursor/rules; HiddenLayer README injections; CVE-2025-54135 full kill chain: one injected Slack message, fetched via MCP, rewrote mcp.json and achieved remote code execution.
CVE counts as stated: OpenClaw 92+ advisories / 9+ formal CVEs in four months; Claude Code 8+; Cursor 8+ plus 94 Chromium. Claude Code March 2026 fix addressed PreToolUse hooks that could bypass deny rules, including enterprise managed settings.
Note: this post is a synthesis, not an independent witness for Ona/HiddenLayer/UpGuard claims. Each claim below is graded REPORTED with its cited audit as the source, and the post itself adds no independent weight.
