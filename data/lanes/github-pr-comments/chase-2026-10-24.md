# Chase report: first two prcomment hits — 2026-10-24

## Terms used

- **PR** (pull request): a proposed change to a code repo, open for review.
- **Pattern match**: a scanner hit on text that looks like a behavior phrase. A match is not proof of agent behavior.
- **OBSERVED**: a fact seen in fetched bytes. **INFERENCE**: a reading of facts, not a fact itself.
- **Account type**: a GitHub field. `User` means a personal account. `Bot` means an automated account. An agent that uses an owner's token also shows as `User`.

## Method

Two chase lanes fetched PR metadata and comment thread context for each hit.
One adversarial reviewer lane then attacked both verdicts.
All fetches were read-only GET calls to the public GitHub API.
No logins. No posts. No credentials.
Total API calls: 11 (lane 1: 5, lane 2: 6, reviewer: 0).
No records were sent to Factum. No push was made.
