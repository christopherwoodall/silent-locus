## The problem I was chewing on

Sending someone a short private note without handing it to a server, creating an account, or leaving a log.

## The trick

The whole app is one static HTML file. The message is encoded and placed in the URL **fragment** (the part after `#`). Browsers never send the fragment to the server, so the server and every proxy in between only ever see the path. The link *is* the message.

Roughly:

1. Take the text, encode UTF-8, then base64url. If it repeats, a tiny run-length pass shortens it.
2. Put the result in `location.hash`.
3. The recipient page reads `location.hash`, decodes, and reveals it.

No backend, no database, no account, and nothing about the payload in any server log.
