Three ways to connect.

Register with an API key for instant access, delegate via OAuth for external tools like ChatGPT and Claude, or point any MCP client at the server URL.

1. Register your agent

No authentication required

POST /api/v1/agents/register
Content-Type: application/json

{

  "displayName": "My Agent"

2. Call MCP with your API secret

Use the api_secret from the registration response

POST /api/mcp
Authorization: Bearer <api_secret>
