## Payment flow (x402 v2)

1. Call any endpoint without payment → receives HTTP 402 with `PAYMENT-REQUIRED` header + JSON body `{accepts: [{scheme:"exact", network:"nano:mainnet", asset:"XNO", payTo:"nano_1yo6c1t64ahfjdw1dxizmbbnpdmbrckwhw9phbg5pdkeubrizga4qhnjmnx7", amount:"<raw>"}]}`
2. Sign and broadcast a Nano send block to the payTo address for the exact amount
3. Retry the request with header `X-PAYMENT: <64-char-hex-block-hash>`
4. Server verifies the block on-ledger and returns the data

## Python client

A Python client wrapping every live Vend endpoint (count from the live x402 manifest) with x402 payment support:
- Install: `pip install https://extract.paypercall.dev/static/packages/vend_client-0.1.0-py3-none-any.whl`
- The wheel ships both the client and the CLI. For the Nano-wallet `[paid]` extra not available via a direct-URL install, run `uv run vend-client` from a repo clone instead.
- Docs: https://paypercall.dev/vend-client
- Dry-run: `client = VendClient()` — returns 402 challenge without paying
- Paid: `client = VendClient(wallet=wallet)` — auto-pays via x402

## MCP server (Model Context Protocol)

All live Vend APIs are exposed as MCP tools (current set from the live `/.well-known/mcp` manifest) — agents in Claude Desktop, Cursor,
VS Code, or any MCP client/agent framework can discover and call them without
signup or API keys (pay per call in Nano):

- **Streamable HTTP endpoint:** `https://extract.paypercall.dev/mcp`
- **stdio:** `npx`/`uvx` equivalent — run `python vend_mcp.py` (stdio, for local clients)
- **Tools:** `extract_url`, `check_link`, `domain_info`, `web_search`,
  `geoip_lookup`, `check_url_status`, `nano_account_info`, `youtube_transcript`
- Each tool call that requires payment returns the exact Nano x402 challenge
  (price in XNO, pay_to address, x402 version 2), so any MCP client can settle
  the on-ledger payment and retry with the block hash.
- Registration: **live in the official MCP Registry** — `dev.paypercall.extract/vend-api-merchant`
  (registry.modelcontextprotocol.io), auto-indexed downstream by mcpi.app, Glama, mcp.directory.
- MCP-client quickstart (adding to Claude / Cursor / ChatGPT, tools & prices, payment flow):
  https://extract.paypercall.dev/static/mcp-client-quickstart.md

## Technical specs

- **Settlement network:** Nano (XNO), `nano:mainnet`
- **Protocol:** x402 v2 (`exact` scheme)
- **Fee:** 0 (Nano has no transaction fees)
- **Finality:** ~1 second
- **Verification:** Self-verifying via on-ledger RPC lookups
- **Conformance:** Stelar 100.0/A, x402 Doctor pass, Bazaar input spec compliant
