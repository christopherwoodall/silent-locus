## Key surprises

1. **xbench-DeepSearch is encrypted** — the dataset card explicitly says data is encrypted against search-engine crawling; plaintext requires decrypt code from `github.com/xbench-ai/xbench-evals`. Not a W2 curl job as-is.
2. **GAIA is fully gated** — unauthenticated downloads return 401 for BOTH validation and test files. The prior note ('only validation/dev public') is wrong per byte measurement.
3. **HLE is gated on HF** (`cais/hle`, gated:auto) despite MIT license — one-click terms acceptance required before any download.
4. **SimpleQA's CSV includes a per-question `urls` field** in metadata — directly useful for trace hunting.
5. **SealQA parquet has `urls`, `topic`, `freshness`, `search_results` columns** (111 + 254 + 254 questions) — trace gold.
6. **FRAMES test.tsv is only 484KB** — 824 questions, cheap to fetch.
7. **No corpora found for Meta, xAI, DeepSeek** (HF + GitHub search, 2026-10-05).

## Recommended W2 priority (highest trace value first)

SealQA (urls+search_results) → SimpleQA (per-question urls) → WebWalkerQA (Root_Url) → BrowseComp-family (encrypted; needs decrypt step) → xbench-DeepSearch (encrypted; needs decrypt step) → FRAMES/FACTS/AssistantBench/WebVoyager → τ-bench/WebArena/Mind2Web/MLE-bench (task-instruction style, no URL fields).
