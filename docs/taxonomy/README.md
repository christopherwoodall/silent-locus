# Taxonomy

This directory documents the classification systems used across the hunt.

## Contents

- `event-schema.md` — the event JSONL schema (fields, types, conventions)
- `record-types.md` — Factum record types and when to use each
- `behavior-categories.md` — AI behavioral analytics categories
- `ttp-taxonomy.md` — tactics, techniques, and procedures

## Principles

- Taxonomy emerges from data, not imposed top-down
- Document what we see, not what we expect
- Keep it simple — a taxonomy nobody uses is worse than none
