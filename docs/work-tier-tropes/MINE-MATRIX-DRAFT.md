# MINE-MATRIX-DRAFT — what analysts should extract per surface tier

Status: draft. Lane worker MINE-MATRIX. Coordinator merges into the final doc.
Style: ASD-STE100. Short sentences. Simple words. Terms defined on first use.

Terms:
- TTP = tactics, techniques, and procedures. A TTP is how an agent does a task.
- IOC = indicator of compromise. A term, hash, IP, or wallet address that marks agent activity.
- POI = platform of interest. A board, panel, or surface. Never a person.
- Beacon = a periodic self-report post an agent leaves in a public place.
- Dead drop = a place where an agent sends or leaves data.
- PoW = proof of work. A small compute challenge that proves a client is real.
- ASN = autonomous system number. The network owner of an IP address.

## Factum type gaps found

Extraction targets with no matching record type in the installed packs:

1. No beacon-cadence record. T2 heartbeat and T4 poll bursts are temporal.
   `behavior.profile` ranks markers but has no timing fields. Needed: a
   cadence observation type (period, burst window, jitter) or timing fields
   on `infra.message`.
2. No TLS-cert/banner fingerprint type. Infra markers columns above need a
   home. `infra.proxy_instance` has host/invocation_shape/live/access only.
   Needed: `infra.banner` or cert/fingerprint fields.
3. No identity-assertion record for T5. Agent-board registration, PoW
   challenges, `.well-known/agent-board.json` schemas collapse into generic
   `web.capture`/`infra.message`. Needed: `infra.identity_assertion` type
   (subject, challenge, schema_keys, realm).
4. No agent-handle observable. Handles like `@head-of-engineering` (T4) go
   to `infra.ioc` as terms — a marker placeholder, not an identity record.
   Needed: `agent_handle` observable linkable to records.
5. No trajectory-step record for scanner-delivered payloads (T7). The 426
   `/base64/` decoded programs are neither `behavior.tool_sequence` (not a
   corpus trajectory) nor plain `web.capture`. Needed: `exfil.program`
   observation or a `dataset.record` slice convention for scanner corpora.
