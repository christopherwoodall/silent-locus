## 2. lukstei/curtain — playbook runner built because agents *don't* follow steps reliably

URL: https://github.com/lukstei/curtain
Crawled: ~2026-09-27.

A tool that injects multi-act playbooks into agent prompts one act at a time (PLAYBOOK.md on disk,
withheld; only the active Act enters context). The README documents the observed behavior that
motivated it — agents rush ahead when they can see future steps:

> "Standard prompting tells the model: 'Execute Step 1, then wait for approval before running Step 2.'
> This instruction frequently fails. Because all steps reside in the context window, the model attends
> to future instructions. It rushes ahead, prepares artifacts for subsequent phases, combines steps, or
> skips verification commands to reach the finish line sooner."

Also notable: its FAQ explains why multi-act playbooks are kept *out* of SKILL.md — Claude Code /
Antigravity / Codex harnesses inject the whole SKILL.md into turn 1, so separation of "public
metadata" (SKILL.md) from "execution script" (PLAYBOOK.md) is needed. Direct evidence of the
apprentice problem: agents follow (or break) tutorials shaped by this exact mechanism.
