# workspace/lists/

## What lives here

Operational inventories. Lists the hunt uses to work, not evidence and not findings.

Examples of what belongs here:

- Marker term lists: terms scanners search for, one exact term per line where the list is a text list.
- URL inventories: known hosts, boards, and surfaces, with their scope status.
- Watchlists: surfaces under standing attention, with the reason each one is watched.

## Rules

- Keep lists exact. Deduplication of a list is case-sensitive for terms. Do not merge near matches silently.
- A list entry is not evidence. Updating a list alone does not establish provenance. Record the evidence behind a new term in the catalog.
- Config targets ARE the scope. There is no separate scope file. Adding a target to config is a TIER-B ship event. It needs the operator's word and a Counsel verdict. No target, no collection.
- Lists hold markers and locators, never human identity. Scope is agents and agent infrastructure only.
- No real list files live here in the profile itself. Real lists enter only through a real run, on a real Hermes instance.
