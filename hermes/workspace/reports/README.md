# workspace/reports/

## What lives here

Reports and writeups. Analysis, triage summaries, and findings, written for the operator.

A report is not evidence. A report cites evidence. Each claim in a report links to its catalog record and its evidence files in `../raw/`.

## Rules

- Write in ASD-STE100 Simplified Technical English: short sentences, simple words, one idea per sentence. Define each term on first use.
- State the grade of each claim: observed, inference, or upstream. State the scope of each novelty check.
- State what is uncertain. State what was not found. An honest null is a good result.
- Every dismissal and every verdict in a report records a reason. No silent dismissals.
- A report never ships outside the instance without a Counsel verdict and the operator's approval. Counsel alone cannot ship. The operator alone cannot ship without Counsel.
- No Factum branding and no GitHub links in outward-facing reports. Link to direct sources only. Full evidence lineage lives in an internal record that never ships. Prcomment evidence is cited via the internal catalog/evidence file, with the GitHub URL kept internal: outward-facing reports carry no GitHub links.
- No real reports live here in the profile itself. Real reports enter only through a real run, on a real Hermes instance.
